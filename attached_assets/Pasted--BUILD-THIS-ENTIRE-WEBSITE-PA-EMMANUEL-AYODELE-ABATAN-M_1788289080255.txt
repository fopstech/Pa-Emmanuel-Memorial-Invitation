another attempt must show:

==================================================
SECURITY
========

Do not rely only on frontend JavaScript to determine whether an invitation is valid.

Check invitation status using the backend/database.

When admitting a guest, make the check-in operation atomic so two phones cannot successfully admit the same invitation at the same time.

The operation should only succeed if:

invitation exists
AND
invitation is not disabled
AND
admitted_count < admission_limit

Then update the invitation immediately.

Record the check-in.

If another request happens after that, it must fail.
